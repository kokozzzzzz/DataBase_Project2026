## 📊 核心实体清单（共 8 张表）

### ③ 设备监控与故障工单
1. **设备运行数据 (`device_telemetry`)**：按分钟采集的电压、电流、功率及故障码等。
2. **告警信息 (`alarm`)**：设备发生的故障告警记录及复核状态。
3. **维修工单 (`maintenance_work_order`)**：针对告警产生的派单、维修及复核闭环记录。

### ⑦ 备件库存与领用管理
4. **备件 (`spare_part`)**：备件档案库。
5. **仓库 (`warehouse`)**：备件存放的物理仓库。
6. **分仓库存 (`inventory`)**：仓库与备件的组合当前库存。
7. **库存流水 (`inventory_transaction`)**：入库、领用、退库、盘点及冲正流水。
8. **工单备件明细 (`work_order_part`)**：维修工单中计划、领用、安装和退回的具体数量明细。

## 💡 设计要点与亮点

1. **逻辑外键约束**：`pile_id`（充电桩）与 `gun_id`（充电枪）属于外部实体（B同学维护）。本模块保留这两个字段作为**逻辑外键**，物理建表时暂不添加数据库级外键约束，避免跨模块建表依赖冲突。
2. **自关联冲正设计**：`库存流水` 表中通过 `related_transaction_id` 实现自关联。库存流水不可物理删除，发生错误时通过生成“冲正”流水来抵消原流水，确保数据可追溯。
3. **组合唯一约束**：
   - 分仓库存：`(仓库编号, 备件编号)` 联合唯一，确保同仓同备件只有一条库存记录。
   - 工单备件明细：`(工单编号, 备件编号, 领用仓库编号)` 联合唯一，防止单张工单重复登记同一备件。
4. **并发与事务控制**：库存数量的更新与库存流水的写入必须在同一个数据库事务中完成；并对 `分仓库存` 增加了 `版本号` 字段以支持乐观锁，防止并发领用导致库存超卖。
