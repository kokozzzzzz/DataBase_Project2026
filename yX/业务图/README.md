# C 模块业务图

本目录按 A、B 模块的业务图形式提供 ③设备监控与故障工单、⑦备件库存与领用管理两条业务线的用例图、鲁棒图和局部 E-R 图。每张图同时保留 Graphviz `.dot` 源文件和 PNG 成图。

| 编号 | 业务线 | 图类型 | 说明 |
|---|---|---|---|
| 01 | ③设备监控与故障工单 | 用例图 | 采样、告警、派单、维修复核和设备恢复参与者 |
| 02 | ⑦备件库存与领用管理 | 用例图 | 收货、计划、领用、安装、退料、调整、冲正和无损耗规则 |
| 03 | ③设备监控与故障工单 | 鲁棒图 | Boundary、Control、Entity 之间的遥测和工单闭环 |
| 04 | ⑦备件库存与领用管理 | 鲁棒图 | 库存写入、工单备件核算及不可变流水 |
| 05 | ③设备监控与故障工单 | 局部 E-R 图 | C 告警工单实体及 B 桩枪逻辑引用 |
| 06 | ⑦备件库存与领用管理 | 局部 E-R 图 | 库存、流水和工单备件之间的关系 |

局部 E-R 图字段以 `yX/sql/C/01_schema.sql` 为准。C 对 B 的桩、枪及共享离线待办使用逻辑引用，不在 C 重复建表；库存流水记录收货、领用、退料、调整和冲正。

## 重新渲染

安装 Graphviz 后，在仓库根目录运行：

```powershell
Get-ChildItem yX\业务图 -Filter *.dot | ForEach-Object {
    $png = [System.IO.Path]::ChangeExtension($_.FullName, ".png")
    dot -Tpng -Gdpi=155 $_.FullName -o $png
}
```
